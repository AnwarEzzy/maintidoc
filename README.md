# MaintiDoc

A multimodal AI assistant for maintenance technicians, providing
source-backed answers from technical documents and images.

## Project objective

Help maintenance technicians find and understand information in
technical manuals, procedures, tables, and diagrams.

Answers must include verifiable references to the source documents
and pages.

## First milestone: Multimodal Agentic RAG

- Upload a PDF containing text, figures, and tables.
- Extract and index its contents.
- Retrieve relevant information to answer questions.
- Display answers with do   cument and page references.
- Use an agent to select appropriate retrieval tools.
